# MemAgent 项目目标

**一句话定位**：让 Agent 跨会话记住用户偏好与历史交互，在「工具调用 + 记忆检索 + Agentic RAG」的闭环中完成复杂任务。


## 一、能力目标

| 维度 | 目标 |
|---|---|
| 工具调用 | Agent 能自主选择 `read` / `write` / `bash` / `web_search` / `knowledge_search` / `memory_search`，并根据结果动态决定下一步 |
| 三层记忆 | 短期会话可恢复、工作记忆可追踪、长期记忆跨会话可召回 |
| 记忆治理 | 冲突可消解、状态可切换、低价值记忆可遗忘，而非只增不减 |
| Agentic RAG | 模型自主控制检索时机与查询改写，检索结果作为工具观察返回，而非直接拼接 |
| 评估可观测 | 每轮对话的工具调用、记忆读写、Token 消耗、执行轨迹可追溯 |


## 二、量化目标

**记忆维度**：
- 跨会话记忆召回准确率 ≥ 85%
- 偏好识别准确率 ≥ 80%
- 冲突消解正确率 ≥ 90%

**工具维度**：
- 工具选择准确率 ≥ 85%
- 工具调用成功率 ≥ 95%

**Agentic RAG 维度**：
- 多跳场景步数比（实际步数 / 理想步数）≤ 1.5
- RAG 相关性评分（Faithfulness）≥ 0.8

**工程维度**：
- 记忆召回 P95 < 200ms
- 记忆写入 P95 < 300ms
- 整体对话 P95 延迟增加 ≤ 500ms（相对无记忆基线）
